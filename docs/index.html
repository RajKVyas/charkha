CHARKHA

A ~1B-parameter depth-recurrent language model that trains and serves on a single consumer GPU (8 GB VRAM).

View on GitHub Tutorial Architecture

Key Features

  • Depth-recurrent core — loops the same transformer blocks multiple times per token. Effort dial (1–16 passes) trades compute for depth at inference.
  • GDN-2 + attention hybrid — Gated Delta Network v2 (linear-time) alternates with sliding-window attention.
  • Consumer GPU training — gradient checkpointing, chunked fused CE, 8-bit optimizer offload. Full 1B config fits 8 GB.
  • Full stack — data prep → training → serving → SFT, distillation, RL, model merging.
  • MIT license — free for research and commercial use.

Quick Start

git clone https://github.com/RajKVyas/charkha.git
cd charkha
python -m charkha._toy --toy   # CPU selftest, no GPU required
